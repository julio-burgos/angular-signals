# Signal Utilities

## `deepSignal<T>(value: T, options?: CreateSignalOptions<T>): WritableSignal<T>`

Creates a signal with deep equality checking using lodash's `isEqual` function.

**Parameters:**
- `value: T` - Initial value for the signal
- `options?: CreateSignalOptions<T>` - Optional Angular signal options

**Returns:** `WritableSignal<T>` - A writable signal that uses deep equality comparison

**Example:**
```ts
import { deepSignal } from '@angular-signals/angular-signals';

const user = deepSignal({ name: 'John', age: 30 });
user.set({ name: 'John', age: 30 }); // No update (deep equal)
user.set({ name: 'Jane', age: 30 }); // Triggers update
```

## `deepComputed<T>(computation: () => T, options?: CreateComputedOptions<T>): Signal<T>`

Creates a computed signal with deep equality checking.

**Parameters:**
- `computation: () => T` - Function that computes the value
- `options?: CreateComputedOptions<T>` - Optional Angular computed options

**Returns:** `Signal<T>` - A read-only signal with deep equality

**Example:**
```ts
import { deepComputed, deepSignal } from '@angular-signals/angular-signals';

const user = deepSignal({ name: 'John', age: 30 });
const displayName = deepComputed(() => `${user().name} (${user().age})`);

console.log(displayName()); // "John (30)"
user.set({ name: 'John', age: 30 }); // No update (deep equal)
```

## `deepLinkedSignal<D>(computation: () => D, options?: { equal?: ValueEqualityFn<D>; debugName?: string }): WritableSignal<D>`

Creates a linked signal with deep equality checking using lodash's `isEqual` function.

**Parameters:**
- `computation: () => D` - The computation function for the linked signal
- `options?: { equal?: ValueEqualityFn<D>; debugName?: string }` - Optional configuration

**Returns:** `WritableSignal<D>` - A writable signal with deep equality comparison

**Example:**
```ts
import { deepLinkedSignal, deepSignal } from '@angular-signals/angular-signals';

const count = deepSignal(0);
const doubled = deepLinkedSignal(() => count() * 2);

console.log(doubled()); // 0
count.set(5);
console.log(doubled()); // 10
```

## `deepLinkedSignal<S, D>(options: { source: () => S; computation: (source: S, previous?: { source: S; value: D }) => D; equal?: ValueEqualityFn<D>; debugName?: string }): WritableSignal<D>`

Creates a linked signal with source and computation, using deep equality checking.

**Parameters:**
- `options.source: () => S` - Source signal function
- `options.computation: (source: S, previous?: { source: S; value: D }) => D` - Computation function
- `options.equal?: ValueEqualityFn<D>` - Optional equality function
- `options.debugName?: string` - Optional debug name

**Returns:** `WritableSignal<D>` - A writable signal with deep equality comparison

**Example:**
```ts
import { deepLinkedSignal, deepSignal } from '@angular-signals/angular-signals';

const items = deepSignal([1, 2, 3]);
const sum = deepLinkedSignal({
  source: () => items(),
  computation: (source) => source.reduce((a, b) => a + b, 0)
});

console.log(sum()); // 6
items.set([1, 2, 3, 4]);
console.log(sum()); // 10
```

## `reactive<T extends Record<string, unknown>>(initialValue: T): ReactiveObject<T>`

Creates a reactive object where each property becomes an individual signal, providing fine-grained reactivity.

**Parameters:**
- `initialValue: T` - The initial object to make reactive

**Returns:** `ReactiveObject<T>` - A reactive object with signal properties and utility methods

**Type Definition:**
```ts
type ReactiveObject<T extends Record<string, unknown>> = {
  [K in keyof T]: WritableSignal<T[K]>;
} & {
  readonly state: Signal<T>;
  readonly update: (partial: Partial<T>) => void;
  readonly reset: () => void;
};
```

**Example:**
```ts
import { reactive } from '@angular-signals/angular-signals';

interface User {
  name: string;
  age: number;
  email: string;
}

const user = reactive<User>({
  name: 'John',
  age: 30,
  email: 'john@example.com'
});

// Access individual signals
console.log(user.name()); // 'John'
console.log(user.age()); // 30

// Update individual properties
user.name.set('Jane');
user.age.update(age => age + 1);

// Get the complete state
console.log(user.state()); // { name: 'Jane', age: 31, email: 'john@example.com' }

// Update multiple properties
user.update({ name: 'Bob', email: 'bob@example.com' });

// Reset to initial values
user.reset();

// Fine-grained reactivity - only name changes trigger this effect
effect(() => {
  console.log('Name changed:', user.name());
});

// Create computed values based on individual signals
const displayText = computed(() => `${user.name()} (${user.age()})`);
```

This utility is perfect for converting plain objects into reactive state where you need fine-grained control over individual property updates, similar to Vue's `reactive()` function.

## `watch<T>(deps: Signal<any>[], callback: (clean: void) => void, options?: CreateEffectOptions): EffectRef`

Creates an effect that runs when any of the dependency signals change.

**Parameters:**
- `deps: Signal<any>[]` - Array of signals to watch
- `callback: (clean: void) => void` - Function to call when dependencies change
- `options?: CreateEffectOptions` - Optional effect configuration

**Returns:** `EffectRef` - Effect reference for cleanup

**Example:**
```ts
import { watch, signal } from '@angular-signals/angular-signals';

const count = signal(0);
const name = signal('John');

const effectRef = watch([count, name], () => {
  console.log('Count or name changed:', count(), name());
});

// Cleanup when needed
effectRef.destroy();
```

This utility is useful when you need to watch multiple signals and perform side effects, similar to React's `useEffect` with multiple dependencies.

## `extract<T>(value: T | (() => T)): T`

Resolves a direct value or a getter function (including Angular Signals).

**Parameters:**
- `value: T | (() => T)` - A value or getter

**Returns:** `T` - The resolved value

**Example:**
```ts
import { signal } from '@angular/core';
import { extract } from '@angular-signals/angular-signals';

const n = extract(1); // 1
const s = signal(2);
const v = extract(s); // 2
```

## `boolAttr(value: unknown): boolean`

Parses an HTML boolean attribute-like value into a boolean.

**Parameters:**
- `value: unknown` - Attribute-like value (e.g. `''`, `'false'`, `true`, `null`)

**Returns:** `boolean` - Parsed boolean

**Example:**
```ts
import { boolAttr } from '@angular-signals/angular-signals';

boolAttr(''); // true
boolAttr('false'); // false
```

## `onCleanup(fn: () => void): void`

Registers a cleanup callback.

- If called inside a callback invoked by this library (e.g. `watch`, `resource`), it registers an effect cleanup.
- Otherwise, it falls back to `DestroyRef.onDestroy` if in an injection context.

**Parameters:**
- `fn: () => void` - Cleanup callback

**Example:**
```ts
import { watch, onCleanup } from '@angular-signals/angular-signals';

watch(() => 1, () => {
  const id = setInterval(() => {}, 1000);
  onCleanup(() => clearInterval(id));
});
```

## `createContext<T>(description?: string): Context<T>`

Creates a typed “context” helper built on Angular DI (Runed-inspired).

This is a small wrapper around `InjectionToken` + `inject()` to make creating and
consuming scoped values ergonomic, similar to Svelte’s context pattern.

**Parameters:**
- `description?: string` - Used for the underlying token name and error messages

**Returns:** `Context<T>` - `{ token, provide, get, getOr, exists }`

**Example:**
```ts
import { Component } from '@angular/core';
import { createContext } from '@angular-signals/angular-signals';

const ThemeContext = createContext<'light' | 'dark'>('Theme');

@Component({
  selector: 'app-parent',
  template: `<app-child />`,
  providers: [ThemeContext.provide('dark')],
})
export class Parent {}

@Component({
  selector: 'app-child',
  template: `Theme: {{ theme }}`,
})
export class Child {
  theme = ThemeContext.get();
}
```

## `resource<S, T>(source, fetcher, options?): ResourceReturn<T>`

Creates an async resource driven by a signal (or getter) source.

**Parameters:**
- `source: S | Signal<S> | (() => S)` - Source value/getter
- `fetcher: (ctx: { value: S; abortSignal: AbortSignal }) => Promise<T>` - Async fetcher
- `options?: ResourceOptions<T>` - Optional configuration (`initialValue`, `lazy`, `debounce`)

**Returns:** `ResourceReturn<T>`:
- `status: Signal<'idle' | 'loading' | 'success' | 'error'>`
- `loading: Signal<boolean>`
- `error: Signal<unknown | null>`
- `current: Signal<T | undefined>`
- `refetch(): void`

**Example:**
```ts
import { signal } from '@angular/core';
import { resource } from '@angular-signals/angular-signals';

const query = signal('hello');
const upper = resource(query, async ({ value }) => value.toUpperCase());
```

## `useSearchParams(options?: SearchParamsOptions): SearchParamsReturn`

Reactive URL query string helpers (browser-only).

**Parameters:**
- `options?: SearchParamsOptions` - Optional configuration:
  - `mode?: 'push' | 'replace'` - History update mode (default: `'replace'`)
  - `preserveHash?: boolean` - Preserve `location.hash` (default: true)

**Returns:** `SearchParamsReturn`:
- `params: Signal<URLSearchParams>` - Current params
- `get(key): string | null`
- `set(key, value): void`
- `remove(key): void`
- `setMany(entries): void`
- `replaceAll(params): void`

**Example:**
```ts
import { useSearchParams } from '@angular-signals/angular-signals';

const sp = useSearchParams({ mode: 'replace' });
sp.set('tab', 'settings');
```

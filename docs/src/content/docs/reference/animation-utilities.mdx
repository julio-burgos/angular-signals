# Animation Utilities

## `spring(initialValue: number, config?: SpringConfig): SpringSignals<number>`
## `spring(initialValue: number[], config?: SpringConfig): SpringSignals<number[]>`

Creates a physics-based spring animation that smoothly interpolates between values.

**Parameters:**
- `initialValue: number | number[]` - The initial value (number or array of numbers)
- `config?: SpringConfig` - Spring configuration with stiffness, damping, and precision

**SpringConfig:**
- `stiffness?: number` - Spring stiffness (default: 0.15)
- `damping?: number` - Spring damping (default: 0.8)
- `precision?: number` - Animation precision threshold (default: 0.01)

**Returns:** `SpringSignals<T>` - Object with `current` (readonly signal) and `target` (writable signal)

**Example:**
```ts
import { spring } from '@angular-signals/angular-signals';

const { current, target } = spring(0, { stiffness: 0.15, damping: 0.8 });

// Update target to animate
target.set(100);

// Read current animated value
console.log(current());
```

## `tween(initialValue: number, options: TweenOptions<number>): TweenSignals<number>`
## `tween(initialValue: number[], options: TweenOptions<number[]>): TweenSignals<number[]>`

Creates a time-based tween animation with easing curves.

**Parameters:**
- `initialValue: number | number[]` - The initial value (number or array of numbers)
- `options: TweenOptions<T>` - Tween configuration

**TweenOptions:**
- `duration: number` - Animation duration in milliseconds
- `delay?: number` - Delay before animation starts (default: 0)
- `easing?: (t: number) => number` - Easing function (default: linear)
- `interpolate?: InterpolateFunction<T>` - Custom interpolation function

**Returns:** `TweenSignals<T>` - Object with `current` (readonly signal) and `target` (writable signal)

**Example:**
```ts
import { tween } from '@angular-signals/angular-signals';

// Basic usage
const { current, target } = tween(0, {
  duration: 1000,
  delay: 500,
  easing: (t) => t * t
});

// With custom interpolation
const { current, target } = tween(0, {
  duration: 1000,
  interpolate: (from, to) => (t) => from + (to - from) * t
});

// Update target to animate
target.set(100);
```

## `useAnimationFrames(options?: AnimationFramesOptions): AnimationFramesReturn`

Runs a `requestAnimationFrame` loop and exposes timing signals.

**Parameters:**
- `options?: AnimationFramesOptions` - Optional configuration:
  - `immediate?: boolean` - Start immediately (default: true)
  - `fpsLimit?: number | null | Signal<number | null>` - Optional FPS limit

**Returns:** `AnimationFramesReturn` - Object with signals and controls:
- `running: Signal<boolean>` - Whether the loop is running
- `time: Signal<number>` - Current frame timestamp
- `delta: Signal<number>` - Time since last emitted frame
- `frame: Signal<number>` - Frame counter
- `start(): void` - Start the loop
- `stop(): void` - Stop the loop

**Example:**
```ts
import { effect } from '@angular/core';
import { useAnimationFrames } from '@angular-signals/angular-signals';

const frames = useAnimationFrames({ fpsLimit: 30 });

effect(() => {
  console.log(frames.frame(), frames.delta());
});
```
